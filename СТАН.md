# UMOD Codex GUI — стан на 2026-09-18

## Що це

Rust GUI-лаунчер для запуску Codex CLI з профілем `umod`.
Вікно: вибрав модель → «Запустити» → відкрився Codex.
Тека: `C:\Users\Гартунг\Desktop\umod-codex-gui`

## Що готово

### Код (написаний, не скомпільований)

- `Cargo.toml` — eframe 0.36 (egui), default-features=false, features=["default_fonts","glow"]
- `src/main.rs` — GUI на egui: вибір моделі, credential, порт, статус проксі,
  кнопки «Запустити Codex» / «Пуск проксі», журнал
- `src/proxy.rs` — логіка umod-token-proxy: пошук credential, пошук скрипта,
  пошук python, старт/стоп/перевірка проксі
- `src/codex.rs` — запуск Codex CLI у новому вікні (cmd /c start на Windows)
- `.cargo/config.toml` — source.replace = vendor (офлайн-збірка)
- `vendor.ps1`, `vendor2.ps1`, `fix-vendor.ps1`, `fix2.ps1`, `fetch_dep.ps1`
  — скрипти розпакування/фіксування vendor

### Залежності

- `vendor/` — 959 розпакованих крейтів
- `.cargo/registry/cache/` — 959 .crate файлів
- egui 0.36.2, eframe 0.36.2, winit 0.30.13, glow, epaint, emath, ecolor —
  усі ключові крейти egui стеку на місці

## Що НЕ готово

### Збірка не пройшла

`cargo build --release --offline` падає — бракує крейтів у vendor.
Дерево залежностей egui велике (~1000+ крейтів), скрипт завантаження
не встиг докачати все (HTTP 429 від crates.io).

### Що робити далі (завтра)

1. **Докачати браковані крейти.** Запустити цикл:
   ```
   cd C:\Users\Гартунг\Desktop\umod-codex-gui
   cargo build --release --offline 2>&1
   ```
   Помилка каже який крейт бракує (напр. "no matching package named `XXX` found").
   Докачати через WSL:
   ```
   bash -c "python3 /mnt/c/Users/Гартунг/AppData/Local/Temp/fetch_all.py"
   ```
   Скрипт `fetch_all.py` у TEMP качає з crates.io і розпаковує у vendor.
   Проблема: crates.io дає 429 (rate limit) — треба паузи між запитами.

2. **Виправлення egui-winit.** У `vendor/egui-winit-0.36.2/Cargo.toml`
   прибрано `smithay-clipboard` з `clipboard` feature (Linux-only).
   Якщо будуть інші Linux-only залежності — робити так само.

3. **Після успішної збірки** — тест GUI, іконка, README.
